# Governance

`guardrails.json` 是身刻跨模型、跨客户端的机器可读约束摘要。

它不是完整需求文档，也不能取代 `AGENTS.md` 和 `docs/` 中的 canonical 文档。它的作用是：

- 在 CI 中检查关键架构状态和硬规则没有被意外删除。
- 为新的 AI 模型提供稳定、无歧义的第一层项目事实。
- 让数据 owner、阶段范围和需要人工确认的操作可被程序读取。

修改规则：

1. 先取得用户明确批准。
2. 同步更新完整文档和 ADR。
3. 再修改本 JSON。
4. 更新 `tests/governance.test.js` 的必要断言。
5. 运行完整测试。

不得为了让测试通过而放宽硬规则。
