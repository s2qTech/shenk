# 变更检查清单

更新日期：2026-07-17

任何跨端、数据、AI、计时器或 Android 变更在实施前后都要使用本清单。小型纯文案修正可标记不适用，但不得跳过安全和真实数据检查。

## 实施前

- [ ] 已阅读 `AGENTS.md` 和当前 `PROJECT_STATE.md`。
- [ ] 已确认当前工作包及进度，没有越过后续包。
- [ ] 已列出受影响的实体、owner、客户端和 API。
- [ ] 已确认是否涉及用户明确批准门槛。
- [ ] 已说明旧数据兼容、迁移、冲突、删除和回退方式。
- [ ] 已检查是否会影响 Web、Web timer、Worker 或 Android 中的其他一端。
- [ ] 已准备脱敏 fixture，不使用真实健康数据和密钥。

## 数据契约

- [ ] 新字段与 UI 无关，名称在所有端含义一致。
- [ ] JSON Schema、OpenAPI、owner 表和枚举同步更新。
- [ ] v1/v2 兼容范围明确。
- [ ] 未知字段不会在 round-trip 时丢失。
- [ ] patch 空数组保持 no-op，删除必须显式。
- [ ] published template 与历史日期快照不会被原地覆盖。

## 产品语义

- [ ] 日历仍遵守实际 > 当前有效计划 > 本地建议。
- [ ] 缺失仍是缺失，未记录仍是未记录。
- [ ] 计时事实不会未经确认成为正式训练记录。
- [ ] 日常 AI 没有获得修改正式计划的路径。
- [ ] routine 分类完全使用显式 `scene` 和 `role`。

## 离线与同步

- [ ] 保存先写本地并事务性加入 outbox。
- [ ] 断网不阻止核心任务。
- [ ] 重试幂等，刷新或进程退出后队列仍在。
- [ ] 本地 dirty 不被 pull 静默覆盖。
- [ ] 实质冲突可见并可处理。
- [ ] 删除 tombstone 与普通 UI 隐藏行为一致。

## 安全

- [ ] token/API key/密码/迁移码不进入 URL、日志、Git、fixture 或业务实体。
- [ ] 动态文本按纯文本或安全组件渲染。
- [ ] Worker 执行真实服务端权限，不依赖前端隐藏。
- [ ] 导入、AI 输出和云端 payload 有大小、类型和枚举校验。
- [ ] 导出不包含安全配置，除非是专用加密配置档案。

## UI 与设备

- [ ] Android 不是桌面 UI 缩放版。
- [ ] 核心动作可单手完成，并有非手势替代入口。
- [ ] 亮/暗主题、字体放大、TalkBack 和减少动画可用。
- [ ] Timer 旋转、来电、后台和进程恢复不产生第二个时钟。
- [ ] 平台要求的前台通知最小化且锁屏私密。

## 完成前

- [ ] 单元、契约、集成、离线、安全测试通过。
- [ ] 目标设备关键路径手工验证通过。
- [ ] canonical 文档、ADR、PROJECT_STATE 和工作包进度已更新。
- [ ] 有可执行回退方案。
- [ ] Git diff 不含真实数据、截图、token、临时文件或无关改动。
- [ ] 受影响仓库分别提交并推送。
